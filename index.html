Bordercrumb Upload – Privacy Policy

Last updated: 11 November 2026

"Bordercrumb Upload" is a private tool used only by the owner of the YouTube channel Bordercrumb. It is not offered to the public and has no other users.

What the tool accesses

With the owner's consent via Google sign-in, the tool uploads videos to the owner's own YouTube channel and reads the channel's own statistics (YouTube Data API and YouTube Analytics API).

What is stored

The sign-in token is stored only on the owner's own computer. No data is shared with, sold to, or transferred to third parties. No data of other people is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
